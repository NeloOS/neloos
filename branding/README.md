# NeloOS branding

| File | Contents |
|---|---|
| `logo.svg` | The NeloOS logo, "Đài sen" (lotus seed pod seen from above; the linked seeds hint at AI). Used for the About page, PNG renders, docs |
| `logo-small.svg` | Small-size variant for 16–48 px (Start button, app icon): no connecting lines, larger seeds |
| `wallpaper.svg` | Default wallpaper "Vịnh" (Bay) |

At build time the SVG files are rendered to PNG in several sizes (see the `assets`
stage in the `Containerfile`).
